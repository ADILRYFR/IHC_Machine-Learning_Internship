# Multiple Linear Regression: Prediction and Forecasting

Fit regression models for temperature and PM10, evaluate the chronological holdout, and forecast June 2026.

## Files and execution

Run `python 08-multiple-linear-regression/multiple_linear_regression_task8.py`. The source CSV, submitted test predictions, metrics, June forecast and final report are included. Forecasts are not verified observations.

Install the repository's root requirements before running code. Original report filenames and task numbers are preserved.
