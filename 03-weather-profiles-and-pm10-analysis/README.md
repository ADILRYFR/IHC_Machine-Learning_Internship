# Weather Profiles and PM10 Relationships

Examine monthly, seasonal and yearly weather profiles, then align hourly PM10 with weather measurements.

## Files and execution

`Part 1/` contains weather profiles; `Part 2/` contains the aligned PM10-weather analysis. See the `Reports/` directory in each part. This task preserves reports and supporting data.

Install the repository's root requirements before running code. Original report filenames and task numbers are preserved.
