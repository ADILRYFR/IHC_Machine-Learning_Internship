# LSTM Neural Networks for Temperature and PM10

Evaluate NumPy-based LSTM models on the same local-data holdout used for Gradient Boosting.

## Files and execution

Run `python 06-lstm-neural-networks/train_lstm_rnn.py` from the repository root. The script reads its neighbouring master CSV and writes predictions beside it. The report compares results with Gradient Boosting.

Install the repository's root requirements before running code. Original report filenames and task numbers are preserved.
