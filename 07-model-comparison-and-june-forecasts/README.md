# Model Comparison and June Forecasts

Compare verified Gradient Boosting and LSTM test metrics, and produce separate June 2026 forecasts.

## Files and execution

Run `python 07-model-comparison-and-june-forecasts/gradient_boosting_june_forecast.py` and `python 07-model-comparison-and-june-forecasts/lstm_rnn_june_forecast.py`. Each writes its own June CSV. The comparison report uses pre-June observed test data, not unverified June forecasts.

Install the repository's root requirements before running code. Original report filenames and task numbers are preserved.
