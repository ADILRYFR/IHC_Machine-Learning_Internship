# Gradient Boosting for Temperature and PM10

Train separate Gradient Boosting regressors and evaluate on the latest 15 days of the local hourly dataset.

## Files and execution

Run `python 05-gradient-boosting/train_models.py` from the repository root. The source CSV sits beside the script. Reruns write results under `outputs/`; the submitted combined predictions and PDF are retained at this folder's top level.

Install the repository's root requirements before running code. Original report filenames and task numbers are preserved.
