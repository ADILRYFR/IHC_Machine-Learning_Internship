# Weather Station Exploratory Data Analysis

Explore the January-May 2026 weather observations, missing measurements, temporal patterns, and Pearson/Spearman correlations.

## Files and execution

Open `Source files/initial EDA.ipynb` with the kernel working directory set to `Source files`. The CSV is beside the notebook. See `Reports/` for the completed findings.

Install the repository's root requirements before running code. Original report filenames and task numbers are preserved.
